# work_check — 설비 설치 도우미

반도체 자동화 설비(N2 Stocker 등) 현장 설치를 휴대폰으로 진행하는 웹앱입니다. `index.html` 파일 하나로 동작하며 설치가 필요 없습니다.

## 기능

| 탭 | 내용 |
|---|---|
| 작업 | 라인마킹(10단계) → 설비 위치 맞춤 → 레벨링 → 락너트 → 최종 완료, 호기별 14단계 안내 |
| 견적 | 공정별 공수 계획, 작업 실적(작업일보), 파츠 리스트, 경비, 누락 점검, 견적서 출력 |
| 설비 | 호기별 가로·세로 크기, 기준선 X·Y값, 모듈 경계 P1·P2, 포트 위치, 허용오차, 줄자 기점 |
| 기록 | 호기별 실측표·레벨링 결과, CSV 저장 |
| 계산 | 대각선, 대각선 보정량, 3:4:5 직각, 줄자 기점 변환 |

### 라인마킹
- 줄자 100 기점 지원: 화면에 읽을 눈금을 크게 표시하고, 읽은 값을 입력하면 실제 거리로 바꿔 OK/NG 판정
- 대각선 판정과 보정 안내 (뒷변을 HP/OP 어느 쪽으로 몇 mm 옮길지)
- 설비 크기를 바꾸면 직각 삼각형(3:4:5) 크기도 자동 조정

### 레벨링
- 발마다 높이(또는 수신기 눈금) 입력 → 올림/내림 양, 볼트 회전수
- 평탄도, 길이·폭 방향 기울기(mm/m), 모서리 우선 조정 순서, 회차별 기록

### 견적
- 표준 공정 13개(자재 입고~정리·대기)와 경비 5개가 기본으로 들어 있음
- 비어 있는 항목은 "누락 점검"에 남고, 안 하는 작업은 "해당 없음"으로 표시해야 빠짐
- 파츠 수량 = 호기당 수량 × 호기 수 × (1 + 여유율), 올림. 레벨링 풋·락너트는 발 개수와 연동
- 견적서: 노무비 + 자재비 + 경비 + 일반관리비 + 이윤 + 부가세, 공급가 천원 미만 절사. HTML(인쇄용)·CSV 저장

## 사용

- GitHub Pages: 저장소 Settings → Pages → Branch `main` / root 로 켜면 `https://johnpark236-tech.github.io/work_check/` 에서 열립니다.
- 데이터는 사용하는 브라우저(localStorage)에 저장됩니다. 기기를 바꾸기 전에 기록 탭에서 CSV로 저장해 두세요.

## 주의

- 허용오차(외곽 ±3mm, 대각선 차 5mm, 평탄도 0.5mm, 기울기 0.1mm/m)와 볼트 피치 2.5mm는 임시 기본값입니다. 도면·설비 사양에 맞게 설비 탭과 레벨링 설정에서 바꾸세요.
- 노임 단가, 파츠 규격·단가, 요율은 비어 있으며 직접 입력해야 합니다.
